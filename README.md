# 🚗 KiloM - Suivi des déplacements & Réclamation de frais

**KiloM** est une application Android moderne et sécurisée conçue pour simplifier le suivi des déplacements, l'optimisation des tournées et la génération automatique de rapports de réclamation de frais de déplacement (conforme aux normes CSSPO).

---

## ✨ Fonctionnalités principales

- **📊 Génération Excel automatique** : Exportation directe de vos réclamations de frais au format `.xlsx` basé sur le modèle officiel.
- **🗺️ Navigation rapide** : Intégration fluide avec vos applications de cartes préférées (*Google Maps*, *Waze*).
- **⚡ Optimisation de parcours** : Calcul automatique et réorganisation des étapes pour minimiser la distance parcourue.
- **🎨 Thèmes personnalisables (Material 3)** : Prise en charge des modes Clair, Sombre, Rose et OLED.
- **🔒 Respect de la vie privée & Mode Hors-ligne** : Vos données restent à 100 % sur votre appareil. Aucune connexion Internet requise, aucun suivi GPS en arrière-plan.

---

## 📥 Téléchargement & Installation

1. Rendez-vous dans la section [**Releases**](../../releases) du dépôt.
2. Téléchargez le fichier **`KiloM-1.2.0.apk`** (ou la version la plus récente).
3. Ouvrez le fichier téléchargé sur votre appareil Android pour l'installer.

> *Remarque : Si votre téléphone bloque l'installation, autorisez l'installation d'applications issues de sources inconnues pour votre navigateur ou votre gestionnaire de fichiers.*

---

## 🛠️ Informations Techniques

- **Langage & Framework** : Java (Android Studio) + WebView local (HTML5 / CSS / JavaScript)
- **Design System** : Material Design 3 (Google)
- **Compatibilité** : Android 8.0 (API 26) et version ultérieure
